Documentación de mantenimiento y extensión

Cómo usar y mantener este archivo
  • Ejecución local: guarde el archivo .html y ábralo con doble clic en cualquier navegador moderno. No necesita servidor, instalación ni API keys. La única conexión externa es la CDN de Chart.js para las gráficas.
  • Persistencia: los datos se guardan automáticamente en el localStorage del navegador. Use Exportar JSON para respaldos portables e Importar JSON para restaurarlos (recomendado si abre el archivo en otro equipo o navegador).
  • Agregar requerimientos/fases/módulos: use los botones «＋ Agregar». Todos los totales, gráficas, ROI y sensibilidad se recalculan automáticamente sin afectar los datos previos.
  • Exportar a PDF: el botón «Exportar PDF» imprime únicamente el resumen ejecutivo con estilos de impresión (@media print).
  • Compatibilidad PowerPoint (PowerUp/Add-in): al ser un HTML simple sin frameworks ni backend, puede incrustarse en un Add-in web de Office o mostrarse vía control WebView. Las tablas pueden copiarse al portapapeles («⧉ Copiar tabla») y pegarse directamente en diapositivas.
Cómo extender el código (para desarrolladores)
  • El estado completo vive en el objeto global state (ver ESTADO_DEFECTO en el script). Para agregar un campo nuevo: añádalo al estado por defecto, cree el input con un id, regístrelo en CAMPOS_SIMPLES y úselo dentro de calcular().
  • Las tablas dinámicas se definen en TABLAS: cada entrada declara sus columnas y la función de render. Agregar una columna = modificar la plantilla de fila y el estado por defecto.
  • Toda la lógica financiera está centralizada en calcular(), que devuelve un único objeto con series mensuales, TCO, ROI, payback y break-even. Las gráficas solo leen ese objeto, de modo que cualquier cambio de fórmula se propaga a todas las vistas.
  • Convenciones: nombres en español descriptivos, sin dependencias adicionales, funciones puras para cálculo y funciones render* para DOM.
